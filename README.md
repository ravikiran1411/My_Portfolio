# 🚀 Ravi Kiran Allimilli - Portfolio Website

A modern and responsive Full Stack Developer portfolio built with React, Tailwind CSS, and Framer Motion.

https://ravikiran-portfolio-five.vercel.app

* Modern Dark UI

* Smooth Scroll Navigation
* Animated Hero Section
* Skills Marquee Animation
* Featured Projects Showcase
* Education Timeline

## ⚙️ Installation

Clone the repository

```bash
git clone <your-repository-url>
```

Navigate to the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
